# 회사 정보 수집에서 유료 검색 제거

2026-11-26 사용자의 운영 반영 요청에 따른 배포 변경이다.

## 동작

- 회사 조사의 기본값을 `compact`로 전환한다. 기존 회사 조사 캐시를 먼저 재사용하고, 새 회사는 CRM에 명시된 업종·소개·서비스를 사용한다.
- 자료가 부족하고 홈페이지 주소가 등록되어 있으면 해당 페이지의 메타 소개문만 읽는다. 소개는 최대 400자다. 검색 API와 별도 AI 요약 호출은 하지 않는다.
- 홈페이지는 공개 HTTPS만 허용하고 기존 전송 계층의 공개 DNS 검사·접속 IP 고정·이동 재검사를 재사용한다. 총 5초, 512,000바이트, 최대 3회 이동으로 제한한다.
- 홈페이지 접근 실패나 소개문 부재에도 유료 검색으로 전환하지 않는다. 자동 메일은 회사 사실을 추측하지 않는 지침으로 작성하고 빈 조사 결과는 저장하지 않는다. 수동 조사에서는 422로 정보 보강을 안내한다.
- 기존 AI 메일 작성·발송, 제품 검색·필드 보강은 유지한다. 소개문을 읽고 메일을 쓰는 토큰 비용은 남는다.
- 새 API 키나 DB 마이그레이션이 필요 없다. 준비 중이던 검색 공급자 교체·검색 사용량 DB 변경은 이 배포에 포함하지 않았다.

## 운영 설정 및 복구

`AI_COMPANY_RESEARCH_MODE` 미지정 또는 `compact`가 검색 없는 경로다. 필요 시 `search`로 명시하면 기존 Claude 회사 검색으로 복구한다. 그 외 값은 오류로 처리하며 유료 검색으로 자동 전환하지 않는다.

## 검토

- 인증·조직 격리와 메일 발신자·수신자·예약 설정은 변경하지 않는다.
- 회사명/이메일에서 홈페이지·회사 사실을 추측하지 않는다. 자료에 포함된 지시는 무시하도록 메일 작성 프롬프트에 명시한다.
- 간단 정보가 없는 자동 메일은 기존 발송 조건을 통과한 경우 자사 제안 중심으로 작성한다. 기존에 준비된 메일을 다시 생성하거나 임의 재발송하지 않는다.
- 사이트가 소개문을 제공하지 않거나 알 수 없는 사용자 정의 필드명만 있으면 새 회사 정보를 얻지 못한다. 홈페이지의 자기소개를 재무·채용·직원수 검증으로 취급하지 않는다.

## 배포 전 검증

- 운영용으로 분리한 변경의 관련 테스트 126개 통과.
- 변경 파일 ESLint와 `git diff --check` 통과.
- 실제 공개 홈페이지 2곳에서 별도 AI 호출 없이 소개문 추출 확인.
- `pnpm run build:cloudtype` 전체 빌드 통과. 로컬 빌드 전용 `DATABASE_URL`과 `JWT_SECRET`을 지정해 검증했으며 실제 운영 DB에는 연결하지 않았다. 로컬 의존성 junction에 따른 standalone 추적 경고가 있어 로컬 산출물을 배포하지 않고 CloudType에서 의존성 설치부터 다시 빌드한다.

운영 배포 커밋·상태와 기능 확인 결과는 별도 배포 기록에 남긴다.
